# Математика · Learning Hub

Навчальний простір українською: алгебра, геометрія, тренажер із п’ятьма завданнями та практичні розрахунки.

## Перегляд

Відкрийте `index.html` у браузері. Сторінка не потребує встановлення залежностей.

## Публікація через GitHub Pages

У репозиторії відкрийте **Settings → Pages**. У розділі **Build and deployment** виберіть **Deploy from a branch**, гілку **main**, папку **/(root)** та натисніть **Save**.

Після успішної публікації GitHub покаже адресу сайту.
