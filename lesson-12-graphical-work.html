Заняття 12 · Самостійна побудова

Графічна робота

Побудова графіків тригонометричних функцій за допомогою геометричних перетворень.

Навчишся перетворювати опорні точки, визначати період та область значень, а для тангенса - будувати асимптоти.

Головне

Алгоритм побудови

y = a·f(k(x - c)) + b, k ≠ 0

  1. Базовий графікОбери sin x, cos x, tg x або ctg x та запиши його опорні точки.
  2. Масштаб і відображенняКоординати точки стають (tk; a·f(t)). Від’ємне a відображає відносно Ox, від’ємне k - відносно Oy.
  3. ПеренесенняДодай c до абсциси, b до ординати. Отримаєш (tk + c; a·f(t) + b).
  4. Побудова й перевіркаПознач точки, побудуй графік, визнач область визначення, область значень і найменший додатний період.

Проміжок побудови: [-2π; 2π] для всіх завдань. Для tg x і ctg x виключи точки, де функція не визначена; побудуй усі гілки та частини гілок у межах проміжку. Не з’єднуй графік через асимптоти.

Спочатку побудуй у зошиті. Потім перевір у конструкторі.

Масштаб осей і період функції

Масштаб осей

  • Ox - праворуч; Oy - вгору.
  • Познач початок координат O.
  • По Ox: 1 клітинка = π6.
  • По Oy: 1 клітинка = 0,5.

Масштаби осей різні. Для додаткового завдання з тангенсом можна обрати по Ox: 1 клітинка = π8.

Період перетвореної функції

Умови: a ≠ 0, k ≠ 0. T - найменший додатний період.

Синус і косинус:

y = a·sin(k(x - c)) + b
y = a·cos(k(x - c)) + b
T = 2π|k|

Тангенс і котангенс:

y = a·tg(k(x - c)) + b
y = a·ctg(k(x - c)) + b
T = π|k|

Для базових sin x і cos x: T = 2π. Для tg x і ctg x: T = π.

Виконай чотири обов’язкові завдання

03

Перевір результат

Звір побудову за коротким списком.

Підказки за потреби

Відкрий лише те пояснення, яке потрібне зараз.

Як налаштувати конструктор
  1. Обери базову функцію: y = sin x, y = cos x, y = tg x або y = ctg x.
  2. Вертикальний масштаб - a. Помнож ординати на a. При |a| > 1 графік розтягується вздовж Oy, при 0 < |a| < 1 - стискається. Якщо a < 0, додається відображення відносно Ox. Для синуса й косинуса амплітуда дорівнює |a|; для тангенса й котангенса амплітуду не визначають.
  3. Горизонтальний масштаб - k ≠ 0. Поділи абсциси на k. При |k| > 1 графік стискається вздовж Ox, при 0 < |k| < 1 - розтягується. Якщо k < 0, графік також відображається відносно Oy до перенесення на c. За a ≠ 0: T = 2π|k| для sin x і cos x; T = π|k| для tg x і ctg x.
  4. Горизонтальне перенесення - c. Додай c до абсцис. Додатне c переносить графік вправо, від’ємне - вліво. Наприклад, x − π2 означає перенесення вправо на π2. Крок повзунка c - π12 радіана.
  5. Вертикальне перенесення - b. Додай b до ординат. Додатне b переносить графік вгору, від’ємне - вниз.

Приклад налаштувань для зразка нижче: sin x; a = 2; k = 1; c = π2; b = 1. Кнопка «Базовий графік» повертає a = 1, k = 1, c = 0, b = 0 для обраної функції. «Спробувати зразок» встановлює наведені параметри.

Сірий пунктир показує базовий графік, синя лінія - результат. Спочатку передбач перетворення й побудуй графік у зошиті, потім перевір у конструкторі. Під час анімації формула позначена як цільова; опорні точки з’являються після завершення.

Як працюють від’ємні a та k

a < 0 змінює знак ординат - відображення відносно Ox. k < 0 змінює знак абсцис перед перенесенням - відображення відносно Oy. Період обчислюємо через |k|.

Порівняй у конструкторі y = −sin x та y = sin(−x). Для синуса графіки збігаються, бо sin(−x) = −sin x. Для косинуса cos(−x) = cos x, тому горизонтальне відображення не змінює базового графіка.

Для tg x і ctg x також f(−x) = −f(x). Якщо одночасно a = −1 і k = −1, то −sin(−x) = sin x.

Спробуй y = sin(−2x): a = 1, k = −2, c = 0, b = 0. T = π; опорні точки можна отримати діленням t на −2.

При c ≠ 0 відображення відносно Oy виконується до перенесення. Відображення вже перенесеного графіка відносно прямої x = c - рівносильний опис.
